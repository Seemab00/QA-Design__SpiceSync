# SpiceSync - SQE & SCD Artifacts

## 📌 About

**SpiceSync** is a food ordering system designed for Pakistani users with AI recommendations, regional spice customization, and multilingual support. This repository contains **Software Quality Engineering (SQE)** and **Software Construction Development (SCD)** artifacts.

---

## 📁 Artifacts

### SCD Artifacts
- Functional & Non-Functional Requirements
- UML Class Diagram
- Activity/Swimlane Diagram
- MVC Architecture

### SQE Artifacts
- 300 Test Cases (3 Modules × 10 Features)
- Defect Log (10 Defects)
- Root Cause Analysis
- Quality Metrics
